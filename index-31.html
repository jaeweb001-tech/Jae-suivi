🚀 Guide de déploiement (GitHub + Firebase)

1. Créer un projet Firebase
  1. Allez sur console.firebase.google.com
  2. Créez un projet (ex. jae-suivi)
  3. Activez Authentication → méthode E-mail/Mot de passe
  4. Créez une base Firestore (mode production)
  5. Dans Paramètres du projet → Vos applications → Ajouter une app Web, copiez la config

2. Coller la config dans ce fichier
  1. Ouvrez ce fichier HTML
  2. Cherchez FIREBASE_CONFIG dans le script
  3. Remplacez les valeurs par celles de votre projet Firebase

3. Règles de sécurité Firestore (recommandées) 
rules_version = '2';
service cloud.firestore {
  match /databases/{database}/documents {
    match /nouveaux/{docId} {
      allow read, write: if request.auth != null;
    }
  }
}

4. Héberger sur GitHub Pages
  1. Créez un dépôt GitHub (ex. jae-suivi)
  2. Uploadez ce fichier (renommez-le en index.html)
  3. Settings → Pages → Source : branch main / dossier /
  4. Dans Firebase Console → Authentication → Settings → Authorized domains : ajoutez votre domaine GitHub Pages
